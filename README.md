# Roulette Pattern Lab

Dual-board roulette simulator and recent-spin analysis dashboard.

- American wheel: 0, 00, 1–36
- European wheel: 0, 1–36
- Physical-style numbered wheel and animated ball
- Up to 30 recent spins
- Hot/cold, frequency, red/black, odd/even, high/low, dozens, columns, and repeat analysis
- Casino Random mode
- Pattern Simulation mode

Pattern Simulation imitates characteristics of the entered sample. It does not predict an independent real casino spin.
